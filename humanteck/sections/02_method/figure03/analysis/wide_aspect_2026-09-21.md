# Fig.2 가로 비율 확장

- 사용자 요청: 현재 내부 배치를 유지하고 높이는 그대로 둔 채 가로를 늘린다.
- SVG 1500×1205 → 2100×1205, PDF 86.49×69.48 → 121.08×69.48mm. 물리적 unit scale은 그대로다.
- 그래프 x축 범위와 세 이미지 묶음의 중심 간격을 가로로 넓혔다. 글자 크기, 모든 y 좌표, 전체 사진 및 정사각형 확대창 크기·종횡비는 유지했다.
- 현재 실제 800 / 1,400 / 2,600 iteration 이미지, ROI, 측정값28개 및 주석 기준 유지.
- 최소 곡선–이미지 수직 간격3.19mm, PDF word bbox 중첩·페이지 밖 텍스트0개. 기존 이미지 hash와 y/width/height 동일성 확인.
- current/와 두 원고용 PDF를 동기화했다. paper.tex의 삽입 폭·float 설정과 캡션은 변경하지 않았다.
- 따라서 기존 단 폭 width=linewidth 삽입에서는 도판이1/1.4로 축소되어 표시 높이49.63mm가 된다. 요청한69.48mm 높이 유지는 독립 PDF 기준이다. 이 차이를 사용자에게 설명했다.
- 직전 결과는 archive/before_wide_aspect_2026-09-21/에 보존했다. 전체 원고 컴파일은 수행하지 않았다.
