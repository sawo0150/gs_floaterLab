# Fig.2 글자 확대

사용자 요청에 따라 도판 비율·사진·곡선·텍스트 위치를 전부 유지하고 font-size만 변경했다.
숫자/가로 축 제목/범례/시점 표시/상단 주석은20% 확대했다.
세로 축 제목은 기존 위치에서 페이지 밖으로 나가지 않도록12.5% 확대했다.
SVG 전 요소를 비교하여 font-size 이외의 속성과 내용이 모두 동일함을 검증했다.
PDF 글자 겹침0건, 페이지 이탈0건. PDF 축소 렌더를 확인하고 current/와 원고 PDF 두 개를 동기화했다.
