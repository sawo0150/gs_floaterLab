# Abstract

현재는 작성하지 않는다. Method 그림과 검증 결과가 정리된 뒤 핵심 메시지를 압축한다.

- 제33회 샘플: Abstract 15줄 이내. 전체 Extended Abstract는 참고문헌 포함 2쪽 이내.
- 수상자 팁: 목적, 핵심 통찰, 접근법, 대표 수치와 실용적 의미를 일관되게 전달.
- 수치에는 비교 대상·예산·평가 조건을 붙인다. 같은 update에서의 품질 개선을 wall-clock 가속으로 바꾸지 않는다.
- 미확정 기하 loss 및 검증되지 않은 floater 제거를 확정 성과처럼 쓰지 않는다.
