- `HumanTeck_Song_s_intern/`: 전달받은 Overleaf 예시. 원본을 보존하며 아직 우리 연구로 교체하지 않는다.

연구 내용의 기준은 [현재 Method TeX](../paper/latex/sec/4_method.tex)와 [Experiments TeX](../paper/latex/sec/5_results.tex)다. `paper/sections/`의 과거 계획은 폴더 구성만 참고하며, 오래된 명칭이나 폐기된 설계를 복원하지 않는다.

형식 기준은 `ref/1_33rd_paper_guide.pdf`와 `ref/2_33rd_abstract_sample.docx`다. 수상자의 제32회 사례와 비공식 LaTeX class를 현행 규정 자체로 취급하지 않는다.
