# LEGACY — batch quality and early incremental foundations

이 campaign은 현재 B-track 구현의 직접 출발점이 아니라 배경 지식이다.

| 묶음 | 대표 실험 | 남은 결론 |
|---|---|---|
| batch 3DGS 상한 | exp01–37 | 고품질 batch baseline과 density/floater 진단 |
| carve/floater | exp38–47 | exp44d2에서 batch 품질과 floater 억제 동시 달성 |
| 초기 incremental | exp48–51 | held-out 평가가 필수이며 단순 완주는 성공이 아님 |

상세 내용은 [chronological ledger](../../INDEX.md)의 해당 번호와
`context/rounds/`를 사용한다. 새 online mapping 방법을 이 campaign의 오래된
absolute frame cutoff에서 시작하면 안 된다.
