1. 연구 질문

목표: 모든 free-space Gaussian을 없애는 것이 아니다. 관측된 terminal surface의 density component와 분리되어 앞쪽에 남은 Gaussian만 억제한다.

기존 depth supervision은 주로 terminal surface의 위치를 정렬한다. 여기에 transit 관측을 더하면 “이 구간에서는 ray가 아직 종료되면 안 된다”는 negative occupancy evidence를 얻는다. 판별과 opacity 최적화를 분리해야 수렴 중인 넓은 surface support를 보존할 수 있다.

2. 먼저 detachment를 판별한다

3D Gaussian을 keyframe ray 위의 1D density로 제한한다. 이 판별에는 compositing transmittance Tᵢᵣ를 쓰지 않는다. 강한 앞쪽 floater가 뒤의 surface component를 숨기는 순환을 막기 위해서다.

ρᵢₖᵣ(t) = oᵢ Aᵢₖᵣ exp(−(t − μᵢₖᵣ)² / 2σ²ᵢₖᵣ) ρₖᵣ(t) = Σᵢ ρᵢₖᵣ(t) p*ₖᵣ = terminal depth zₖᵣ에 대응하는 density peak bₖᵣ = p*ₖᵣ 앞에서 마지막으로 확인되는 density valley mᵢₖ = 1 if Gaussian i의 현재-KF support가 bₖᵣ 앞 component에 속함 0 otherwise; terminal peak/valley가 불명확해도 0 (abstain)

Terminal-conditioned component

렌더된 최대 peak를 곧바로 surface로 쓰지 않는다. KF depth zₖᵣ가 지지하는 peak를 surface component로 선택하므로 강한 floater가 mode를 차지해도 기준이 뒤집히지 않는다.

Topology, not fixed 3σ

임의의 κσ surface band로 자르지 않고 두 component 사이의 valley를 경계로 쓴다. 하나의 넓은 surface mode뿐이거나 valley가 불명확하면 carve하지 않는다.

3. 왜 loss에는 Tᵢ가 없는가?

Detached 구간에서 관측된 사건은 “어느 Gaussian에서 처음 hit했는가”가 아니라 “그 구간 전체를 통과했다”이다. 그 likelihood를 쓰면 transmittance 곱은 로그 안에서 Gaussian별 optical thickness의 합으로 바뀐다.

Detector는 같고 action만 다르다. 두 arm 모두 pixel footprint가 곱해진 αᵢₖᵣ가 아니라 Gaussian 자체 opacity oᵢ를 누른다. NLL은 high-opacity에서 더 강하다는 수학적 장점이 있다. 1.5× baseline에서는 더 완만한 direct-alpha가 안정적이었지만, final-v7 1×에서는 두 action 모두 nominal/dilated region을 악화시켰다. 즉 analytic gradient만으로 action을 선택할 근거는 없다.

4. Persistent multi-view score도 필요 없다

mᵢₖ는 현재 KF에서만 존재하는 일회성 mask다. 현재 depth-loss step에서 만들고 같은 backward에 사용한 뒤 폐기한다. Gaussian ID별 score나 transit/terminal count를 topology 변화에 맞춰 관리하지 않는다.

Keyframe replay가 여러 view의 loss를 순차적으로 샘플링하므로 multi-view evidence는 optimizer gradient에 암묵적으로 누적된다. 진짜 floater는 여러 KF에서 반복 압력을 받고, 한 KF의 일시적 depth·pose 오류는 한 번의 제한된 update로 희석된다.

단, score가 사라지는 대신 view selection이 중요해진다. 같은 방향의 KF만 과도하게 replay하면 같은 판정이 반복된다. 그러나 이 문제는 별도 evidence field가 아니라 기존 KF sampler의 coverage와 per-view loss normalization 문제로 다룬다.

기존 pruning여러 update 뒤에도 opacity가 낮은 primitive를 topology에서 정리초기 실험에서는 carve hard-prune를 추가하지 않음

Transit evidence는 “여기에 있으면 안 된다”는 것은 알려주지만 “어느 surface로 이동해야 한다”는 방향은 제공하지 않는다. 따라서 모호한 xyz force 대신 opacity를 가역적으로 낮추는 것이 자연스럽다. 잘못 판정되면 이후 RGB gradient가 opacity를 회복할 수 있다.

6. 기존 carve와 달라지는 점

현재 score-based carve

  • ray를 3D voxel의 transit/terminal count로 누적
  • 수동 terminal weight가 포함된 위치 score
  • Gaussian score × whole opacity pressure
  • 실제 ray 기여와 떨어진 상태로 동작 가능

제안하는 direct loss

  • 현재 depth KF에서 terminal-conditioned component를 직접 구성
  • density valley로 surface-connected와 detached를 분리
  • Tᵢ 없이 primitive opacity를 직접 최적화; alpha와 NLL action 비교
  • persistent score·landmark·xyz attractor 불필요

7. 최소 구현 경계

  1. 기존 depth-bearing KF가 RGBD loss를 계산하는 mapping step에만 detector와 loss를 붙인다.
  2. optimizer step마다 현재 RGBD view 중 하나만 round-robin으로 선택한다. 여러 view를 합산하는 step도 detector 호출은 1회다.
  3. 선택된 KF pose·online depth·intrinsics를 재사용하며 별도 depth rendering이나 renderer visibility를 요구하지 않는다.
  4. Gaussian의 camera-space depth와 ray-projected covariance로 transmittance 없는 density mixture를 계산한다.
  5. mᵢₖ는 no_grad로 만들고, 같은 step에서 direct sigmoid(_opacity) 또는 NLL softplus(_opacity)를 기존 loss에 더한 뒤 폐기한다.
  6. hard pruning, newborn gate, xyz force, persistent carve score는 모두 끈다.
  7. strict causal 조건에서 control과 동일한 KF/view 및 optimizer budget으로 비교한다.

현재 renderer의 contribution_mass는 재사용하지 않는다. 이것은 Σ Tᵢαᵢ이므로 opacity shielding을 다시 도입한다. 현재 renderer가 내는 expected depth만으로는 component 분리가 자동으로 생기지 않으므로, 초기 구현은 Python/Torch의 Gaussian projection detector로 시작하고 비용이 확인된 뒤에만 auxiliary CUDA output을 고려한다.

8.2 반례와 현재 판정

A1 detector-only는 timing control이 되지 못했다. λ=0인데 trajectory Sim3 scale이 .2506, median residual이 1.25 m로 붕괴했고, view pool과 PGBA 경로도 다른 arm과 갈라졌다. 이 strict streaming 구현은 작은 GPU timing 차이가 tracking/mapping interleaving을 바꾸므로 단일 run의 dB 차이를 순수 loss 효과로 해석하면 안 된다.
  • Implementation PASS: 43개 detector/gradient/기존 carve 회귀 test 통과. 선택된 row의 opacity만 gradient를 받고 xyz는 받지 않는다.
  • 1.5× baseline quality feasibility PASS: active A2/A3 둘 다 zero-tail held-out 27 dB를 유지했다.
  • 1.5× baseline runtime PASS: control 대비 전체 loop 차이는 +0.015/+0.031 s. 100k Gaussian microbenchmark는 detector 1.17 ms/call, peak allocation 약 94 MB였다.
  • NLL-vs-alpha: analytic gradient는 NLL이 high-opacity saturation을 제거하지만, 아래 manual-region 결과에서는 direct alpha가 더 일관되게 개선됐다.
  • Floater/geometry single-seed positive: FastMRI의 aria1253 manual-region GT를 복구해 평가한 결과 direct alpha는 erosion/nominal/dilation 모두에서 visible floater를 줄였다. 반복 seed 전까지 범용 PASS로 확장하지 않는다.
8.3 복구된 manual-region GT 평가. ORB-frame voxel mask와 ORB keyframe trajectory를 FastMRI에서 복구하고, 각 VIGS run을 trajectory Umeyama Sim3로 사후 정합했다. control/alpha/NLL의 alignment median은 2.71/2.95/2.17 cm, p90은 4.42/4.89/3.73 cm였다.

9. 논문 포지셔닝의 경계

Empty-space density 억제 자체는 기존 연구에 있다. 예를 들어 Urban Radiance Fields와 MeshLRM도 camera–surface 구간을 제약한다. 따라서 contribution 후보는 다음 결합에 있다.

Detachment-aware, primitive-level, causal: terminal-conditioned density topology로 surface-connected support를 보호하고, 현재 KF의 일회성 detached label을 visibility-independent primitive opacity penalty로 바꾸며, online replay 자체가 multi-view evidence를 누적하는 score-free opacity-to-pruning 과정.

Empty-space NLL 또는 opacity suppression 자체는 contribution으로 주장할 수 없다. 핵심 후보는 surface inflation을 보존하는 detachment 판별과 그것을 별도 3D score 없이 incremental KF optimization에 결합하는 방식이다.
