1. 최종 판정

달성28 dB급 PSNR을 유지했다. 학습에서 완전히 제외된 fixed held-out 평가에서 aria1253은 27.9331 dB, aria301_305는 30.6697 dB다. 전체 trajectory 평균은 각각 28.0303/30.6990 dB다.

baseline 수준visible floater는 두 장면 모두 baseline의 8% 이내다. opacity > 0.3 nominal count는 1253이 118→126, 305가 491→529다. 각각 +6.8%, +7.7%다.

주의Sim3 정합 후 만든 수동 region mask는 경계 이동에 민감하다. erosion/dilation에서는 우열이 뒤집히므로 nominal 숫자 하나를 정확한 절대 개수처럼 해석하면 안 된다. 따라서 이 결과는 “baseline-level near pass”이지 “baseline 이하”라는 뜻은 아니다. 이 보고서의 PASS는 측정 오차보다 작은 baseline-level 동등성 판정이다.

view-set과 순서

  • view-set membership는 도착한 두 keyframe 사이에서 temporal maximin으로 bootstrap하고, 각 view가 충분한 학습 기회를 받도록 service-credit water filling으로 점진적으로 확장한다. keyframe과 admitted dense frame은 하나의 action pool에서 함께 service된다.
  • 학습 순서는 Stage C에서 가장 안정적이었던 seeded shuffle이다. Fisher novelty-first 순서는 사용하지 않는다.
  • Fisher는 RGB view 순위를 지배하지 않고, 3D free-space 판단이 서로 다른 방향의 ray로 지지되는지 검사하는 geometry confidence로만 사용한다.
  • fixed evaluation frame은 학습 pool에서 제외된다. post-stream 단계는 평가만 수행하며 map update는 0회다.

dense geometry는 제한하지 않음

dense action은 RGB-only이지만 xyz·rotation·scale·opacity 전체 optimizer를 그대로 사용한다. keyframe action은 같은 map() 안에서 RGBD+normal loss를 사용한다. appearance-only mask나 replay 후 scale projection을 적용하지 않는다. 이후 frontier map()가 dense에서 배운 scale을 다시 0.1로 전역 투영하던 숨은 경로도 --mapping_preserve_dense_geometry_scale로 제거했다.

그 결과 최종 max scale은 1253 21.97, 305 22.59까지 열려 있다. 이는 사용자 요구대로 geometry freedom을 보존한 증거인 동시에, 일부 거대 splat을 별도 품질 축으로 점검해야 한다는 경고이기도 하다.

4. carve와 Fisher의 수학적 역할

keyframe의 BA-refined depth를 3D point로 역투영하고, 해당 camera center에서 point 직전까지를 free-space transit, point 부근을 terminal surface evidence로 누적한다. 이것은 sampled RGB frame의 2D rendering loss가 아니라 map 전체에 대한 3D field다.

ρ(x) = transit(x) / [transit(x) + 3·terminal(x) + ε] w(x) = ρ(x) · min(d₅(x, anchors) / 0.25m, 1) s(x) = w(x) · [1 − maxOpacity₀.₀₅ₘ(x)]

각 voxel에는 관측 ray 방향을 13개의 undirected bin으로 누적한다. 방향 d 한 개의 위치 정보는 I − ddᵀ로 근사하고, 여러 방향의 조건성을 다음처럼 정규화한다.

F(x) = Σᵣ [I − dᵣdᵣᵀ] q_F(x) = λ_min(F) / [trace(F)/3] ∈ [0,1]

최종 soft opacity 압력은 score가 0.5보다 크고 q_F > 0.2인 Gaussian에만 들어간다.

L_carve = 0.02 · mean[s(x)·q_F(x)·opacity(x)] opacity ← opacity · [1 − 0.5·s(x)·q_F(x)] (새 evidence generation에서만) Σ removed visual contribution / total contribution ≤ 0.0075
  • hard xyz force는 0이다. surface thickness를 강제로 얇게 만들지 않는다.
  • hard contribution prune도 최종 설정에서는 끈다.
  • newborn gate는 score 0.95와 Fisher 0.2를 동시에 요구하지만, 최종 두 run에서는 실제 삭제 0개였다.
  • 핵심 효과는 되돌릴 수 있는 opacity gradient와 evidence-event proximal update다. 뒤의 RGB gradient가 필요하면 opacity를 다시 키울 수 있다.

8. 무엇을 결론 내릴 수 있고, 없는가

결론 가능: dense RGB geometry를 제한하지 않아도, Fisher를 novelty-first sampler가 아니라 free-space confidence로 사용하고 carve를 약한 전역 opacity regularizer로 넣고 keyframe RGBD+normal을 같은 action pool에서 service하면, 한 universal 설정으로 두 장면에서 28 dB급 held-out 품질과 baseline 규모의 visible floater를 동시에 얻을 수 있다.

결론 불가: carve가 PSNR 상승의 원인이라고 말할 수 없다. strict online tracking은 run-to-run trajectory 변동이 커서 1253 unrestricted control은 27.09 dB였고 최종 run은 28.03 dB였다. paired fixed-trajectory 실험이 아니므로 차이 전체를 carve 효과로 귀속하지 않는다.

또한: nominal baseline count를 정확히 이긴 것은 아니며, 저-opacity dust와 큰-scale splat 문제도 남는다. 현 구현은 이 한계를 숨기기 위해 manual label을 scheduler에 넣거나 scene별 threshold를 조절하지 않았다.
