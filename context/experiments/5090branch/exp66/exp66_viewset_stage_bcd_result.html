View-set의 구성과 학습 순서를 분리하면 무엇이 수렴을 빠르게 하는가

Stage A에서 관측한 “dense frame이 빠르다”를 곧바로 novelty/Fisher 설명으로 치환하지 않고, (B) 같은 크기의 set을 어떻게 구성할지, (C) 같은 set을 어떤 순서로 학습할지, (D) 한 update의 실제 일반화 이득을 무엇이 예측하는지를 순서대로 분리한 결과 보고서다.

결론부터: 이 장면에서는 pure novelty가 빠른 수렴의 원인이 아니었다. 시간적으로 고르게 분포된 representative set은 약한 AUC 개선만 보였고, novel view를 연속 배치하면 오히려 크게 느려졌다. 반면 작은 held-out reference buffer에 대한 gradient alignment, 특히 Adam이 실제로 만드는 이동까지 반영한 -g_RᵀΔθ_Adam은 one-step 개선량을 매우 잘 예측했다. 따라서 view-set 구성과 update 순서는 서로 다른 문제로 유지해야 한다.

강한 결과: novelty-first는 2, 5, 10, 20, 40, 60, 80, 100초의 모든 nonzero milestone에서 3/3 seeds 모두 shuffle보다 나빴다. 과거 Fisher/novelty-next 실험의 실패가 우연한 최종 품질 차이가 아니라, novel gradient를 연속 배치한 optimization path의 문제일 가능성이 높다.

5. Stage D — 한 frame이 실제로 일반화를 개선하는지 예측할 수 있는가

측정 정의

curve-only held-out split에서 시간적으로 고른 8장을 reference buffer R로 두고, representative set의 coverage-score quantile에서 32개 후보를 골랐다. 각 후보마다 실제 Adam 한 step을 수행해 reference objective의 변화를 측정한 뒤 Gaussian과 Adam state를 원복했다.

g_R = (1 / |R|) Σᵣ ∇θ Lᵣ(θ),   gᵥ = ∇θ Lᵥ(θ)
raw alignment = cos(g_R, gᵥ)
θ′ = AdamStep(θ, gᵥ),   predicted decrease = −g_Rᵀ(θ′−θ)
actual decrease = L_R(θ) − L_R(θ′)

모든 후보 뒤 parameter와 optimizer state의 최대 절대 원복 오차는 0이었다. Stage D 본 실험은 2 seeds × 3 시점 × 32 후보 = 192개의 one-step counterfactual이다.

무엇을 배웠나: 후보 frame의 residual이나 novelty보다 “현재 optimizer가 그 frame으로 실제 어느 방향으로 움직일지”가 held-out one-step 이득을 훨씬 잘 설명했다. 특히 Adam에서는 cos(g_R,g_v)보다 moment/preconditioning을 반영한 −g_RᵀΔθ_Adam이 맞는 1차식이다.
그러나 scheduler 완성은 아니다: reference gradient와 모든 후보의 counterfactual Adam step을 직접 계산한 결과이므로 예측력이 높은 것이 이론적으로 자연스럽다. 이것은 mechanism validation이지 아직 저비용 online score가 아니다. 실제 scheduler에는 작은 audit buffer, top-K에만 probe, probe 비용 차감, 오염 방지가 추가로 필요하다.

Fisher λmin에 대한 정정

32개 후보 gradient로 수백만 차원의 full empirical Fisher를 만들면 rank가 최대 32이므로 full-space λ_min은 항상 0이다. 따라서 “λ_min이 커졌다”는 표현은 이 실험에서 성립하지 않는다. 보고한 값은 32×32 gradient Gram의 비영 spectrum과 effective rank뿐이다.

6. Stage A의 “dense가 빠르다”를 지금 어떻게 설명해야 하는가

현재 증거가 지지하는 설명은 “novel direction을 최대화해서”보다 더 복합적이다.

  1. Membership: keyframe 2fps보다 촘촘한 frame set은 trajectory 사이의 supervision gap을 줄이고 held-out trajectory와 train distribution의 거리를 줄인다.
  2. Redundancy: 서로 가까운 view는 완전히 새로운 제약은 아니지만 gradient 방향의 coherence와 낮은 분산을 제공할 수 있다. pure coverage가 제거해 버린 이 중복이 초기 수렴에는 오히려 유용할 수 있다.
  3. Opportunity: dense membership의 이득은 각 frame이 적절히 반복될 때 나타난다. novelty-first처럼 어려운 방향을 몰아주거나 replacement로 일부 frame을 굶기면 이득이 사라진다.
  4. State dependence: 같은 frame의 유용성도 θ, Adam moment, learning rate에 따라 바뀐다. 따라서 frame 자체에 고정된 “필요 iteration 수”가 있다고 보기 어렵다.
정리: dense의 이득은 “제약의 수/폭”만이 아니라 train–eval 분포 간격, gradient coherence, 공평한 재방문, 현재 optimizer state의 결합으로 보는 편이 데이터와 더 잘 맞는다.

7. 현 시점의 scheduler 설계 원칙

  1. View-set 구성과 순서를 분리한다. 구성 단계는 시간 quota를 먼저 지키고 그 안에서 대표성을 개선한다. 전역 pure novelty는 사용하지 않는다.
  2. 기본 순서는 shuffle-without-replacement다. 이것이 현재 가장 강한 baseline이며 모든 frame에 거의 같은 opportunity를 준다.
  3. Novelty는 admission의 약한 보조항으로만 쓴다. 다음 update를 결정하는 단독 우선순위로 사용하지 않는다.
  4. 선택적 top-K probe를 검토한다. cheap residual/pose/coverage gate로 후보를 줄인 뒤, 작은 protected audit buffer에 대한 optimizer-aware alignment를 top-K에서만 계산한다.
  5. water-filling의 stop 조건은 고정 횟수가 아니다. 예측된 held-out 감소량/비용이 threshold 아래면 그 frame 또는 전체 polish를 멈춘다. Stage D의 40초 결과는 “budget이 남았으니 계속”이 항상 안전하지 않음을 보인다.
a* = argmaxₐ [ predicted held-out decrease(a | θ, Adam state) / measured cost(a) ]

다만 이 식을 실제 online scheduler로 채택하기 전에는 별도 실험이 필요하다. reference buffer 크기, 갱신 주기, top-K 수, probe 비용을 고정한 뒤 shuffle baseline보다 end-to-end AUC가 좋아지는지 확인해야 한다.

8. 한계와 다음 실험

  • Stage B/C는 한 장면의 3 seeds, Stage D는 2 seeds다. 장면 일반화 주장은 아직 할 수 없다.
  • Stage D reference는 curve-only 8 views이며 같은 objective로 gradient와 actual delta를 측정했다. 높은 Taylor correlation은 올바른 sanity check지만 독립 test 성능 보장은 아니다.
  • Stage D 후보는 representative set의 coverage quantile 32개다. 모든 784장에 대한 exhaustive 결론은 아니다.
  • coverage surrogate는 exact Fisher가 아니며, full Fisher λ_min을 측정하지 않았다.
  • 다음 우선순위는 (i) audit 4/8/16 안정성, (ii) top-K=4/8/16 비용 포함 AUC, (iii) 다른 trajectory/scene 반복, (iv) depth/normal geometry metric과의 별도 trade-off다.
