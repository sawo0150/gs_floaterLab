View-set 구성과 Budget-aware 학습 기회 배분

Dense RGB가 keyframe-only보다 빨리 수렴했다는 관측에서 출발해, 지금까지 논의한 Fisher/coverage, gradient alignment, view admission, replay 순서와 GPU budget 배분을 하나의 문제 구조로 정리한다. 이 문서는 설계 워킹노트이며, 수식의 대부분은 아직 exp66에서 직접 검증되지 않았다.

관측 경계 지금 확인된 것과 아직 모르는 것

관측된 사실

동일한 26k-step 평가에서 dense 비중이 커질수록 held-out PSNR이 높았고, keyframe 비중을 높인 arm은 단조롭게 낮아졌다.

별도의 novelty/coverage 우선 sampler는 초반 수렴을 늦췄거나 최종 품질을 악화한 사례가 있다.

아직 열린 질문

Dense의 이점이 view-set의 구성 때문인지, sampling 빈도 때문인지, 또는 둘의 상호작용인지는 완전히 분리되지 않았다.

30 fps 전체가 최적인지, frame마다 몇 번의 update가 필요한지, 그 값이 장면을 넘어 일반화되는지는 모른다.

현재 가장 중요한 정정

“정보가 새로운 view”와 “지금 한 step 학습했을 때 빨리 좋아지는 view”는 같은 개념이 아니다. Fisher/coverage는 장기 observability와 dataset 구성을 설명하는 데 가깝고, 즉시 수렴 속도는 residual, gradient 방향, optimizer 상태와 replay 정도까지 영향을 받는다.

문제 분해 서로 다른 두 결정을 분리한다

PROBLEM A · VIEW-SET / ADMISSION

30개 중 어떤 관측을 지도 학습 pool에 남길 것인가?

목표는 frame 수 자체를 늘리는 것이 아니라, pose가 믿을 만하고 서로 중복되지 않으면서 장면과 평가 분포를 잘 대표하는 관측 집합을 만드는 것이다.

주된 도구: Fisher/coverage, viewing-direction novelty, overlap, pose confidence, coreset.

PROBLEM B · UPDATE ALLOCATION

남긴 관측 중 다음 optimizer update를 누구에게 줄 것인가?

목표는 고정 GPU 시간 안에서 새 frame의 첫 update와 기존 frame의 replay 사이에 학습 기회를 배분하는 것이다.

주된 도구: uniform reshuffling, residual/learning progress, gradient alignment, 실제 ms당 한계 이득.

역할 배치

CONVERGE/Fisher는 주로 Problem A에, validation-gradient/learning-progress는 주로 Problem B에 배치한다. Novelty-only로 두 문제를 동시에 풀려고 하면 새 방향만 연속 선택하는 편향이 생길 수 있다.

수학적 배경 Dense set과 한 장씩의 novelty는 왜 다를 수 있나

고정된 view-set D의 평균 loss와 gradient를 다음처럼 둔다. Uniform sampling을 하면 매 step의 gradient는 이 평균 gradient의 unbiased estimator가 된다.

LD(θ) = (1/|D|) Σv∈D ℓv(θ)   ,   gD = (1/|D|) Σv∈D gv

Dense set의 개별 frame gradient가 모두 evaluation gradient와 잘 맞을 필요는 없다. 여러 시점의 gradient를 평균했을 때 편향과 noise가 상쇄되어 gD가 전체 장면 목표에 가까워질 수 있다. 반대로 매번 가장 novel한 한 장만 고르면 이 평균을 따르지 않고, 시간에 따라 이동하는 novelty-weighted objective를 최적화한다.

Uniform: E[gt] = gD    /    Novelty-first: E[gt] = Σv qt(v)gv,   qt ≠ 1/|D|

국소 선형화에서는 set-level Gauss–Newton/Fisher 행렬 HD ≈ |D|−1ΣJvTWvJv의 spectrum이 수렴에 영향을 준다. Dense view가 기존에 약했던 방향을 보강하면 conditioning이 좋아질 수 있지만, 중복 frame을 단순히 늘리는 것만으로는 보장되지 않는다.

View-set 최종 정책은 “몇 fps”로 고정하지 않는다

원칙

K=2,4,8,16,30 sweep은 dense 효과의 포화 지점을 확인하는 진단 실험이다. 최종 online 정책의 하이퍼파라미터를 “8 fps”로 고정하기 위한 실험이 아니다.

실제 정책에서는 raw frame을 보관하는 비용과 optimizer update 비용을 구분한다. CPU 메모리에 frame을 보관하는 비용이 작다면 30장을 받아도 되지만, GPU 학습에서 실제로 기회를 받은 frame만 effective view-set이 된다. 따라서 active set의 크기는 아래 두 방식 중 하나로 정할 수 있다.

OPTION A · HARD ACTIVE-SET

Memory/latency cap으로 최대 M개 유지

새 frame의 marginal coverage가 기존의 가장 중복된 frame보다 클 때 교체한다. M은 fps가 아니라 메모리·조회 지연 한계로 정한다.

OPTION B · UNIFIED ACTION

첫 학습과 replay를 같은 budget에서 경쟁

아직 안 쓴 frame의 첫 update도 하나의 action, 기존 frame의 재학습도 하나의 action으로 본다. 한계 이득이 0이면 자동으로 선택되지 않아 별도의 K가 필요 없다.

현재 권장 해석

개념적으로는 Option B가 가장 깔끔하다. 구현 안정성을 위해서는 bounded active buffer를 함께 두되, 그 크기는 최종 품질을 직접 튜닝한 fps가 아니라 시스템 메모리/latency cap으로 둔다.

필요 iteration 미리 아는 상수가 아니라 포화 속도를 추정한다

frame v가 n번의 학습 기회를 받았을 때 얻는 누적 이득을 설명용으로 다음처럼 근사한다.

Gv(n) = Av(1 − exp(−n/τv))
Av: 총 잠재가치 · τv: 그 가치를 흡수하는 데 필요한 속도 상수
MGv(n) = dGv/dn = (Av/τv) exp(−n/τv)
같은 frame에 기회를 더 줄수록 다음 한 번의 이득은 감소한다.

하지만 Av와 τv를 사전에 정확히 알 수는 없다. 첫 구현에서는 한두 번의 probe update 후 실제 reference/neighbor loss 감소량을 측정하고 EMA로 갱신한다.

m̂v(t) = EMA[(LR(θbefore) − LR(θafter)) / GPU-ms]
모델의 한계

3DGS 파라미터는 view 사이에서 공유된다. 따라서 한 frame을 직접 학습하지 않아도 인접 frame update로 그 loss가 내려갈 수 있다. 위 곡선은 독립 frame 모델이 아니라 설명용 근사이며, 실제 추정 단위는 frame 하나보다 visible-Gaussian/view-direction이 비슷한 view cluster가 더 타당할 수 있다.

Water-filling “모두에게 같은 횟수” 대신 한계 이득을 맞춘다

Water-filling은 제한된 자원을 여러 대상에 나눌 때, 다음 한 단위를 넣어서 얻는 이득이 큰 곳부터 채우는 고전적인 자원배분 비유다. 여기서 물은 GPU 시간이고, 각 통은 view 또는 view cluster다.

View A초기 이득 큼
여러 번 배정현재 MG/ms = μ
View B빨리 포화
적게 배정현재 MG/ms = μ
View C비싸거나 가치 낮음
거의 미배정초기 MG/ms ≤ μ

실제로 수위를 맞추는 것이 아니라, 선택된 대상들의 “다음 GPU 1 ms당 기대 이득”이 같아질 때까지 배분한다.

maximize Σv Gv(nv)    subject to    Σv cvnv ≤ B
active view의 최적 조건:   MGv(nv)/cv = μ
nv* = τv[log(Av/(μcvτv))]+
μ의 뜻

μ는 GPU 시간의 그림자가격(shadow price)이다. Tracking queue가 밀리거나 deadline이 가까우면 μ를 높여 큰 이득의 update만 허용한다. Idle budget이 넉넉하면 μ를 낮춰 더 많은 view와 replay에 기회를 준다.

통합 scheduler Novelty는 첫 기회의 prior, 실측 progress는 replay의 근거

U(v,t) = [m̂v(t) + λtN(v | Dt)] · pv / cv
항의미주된 역할주의점
N(v | D_t)현재 set에 조건부인 coverage/view-direction novelty아직 안 써본 frame의 첫 기회단독 최대화하면 novelty-only 실패 반복 가능
m̂_v(t)최근 reference 또는 neighbor loss의 실제 감소량replay가 아직 가치 있는지 판단final test set으로 측정하면 leakage
p_vpose, blur, exposure 등 관측 신뢰도잘못된 hard frame 차단단순 residual은 pose error와 혼동
c_v실측 render+backward+optimizer ms의 EMA시간 budget에 맞춘 비교step 수보다 wall-clock을 써야 함
  1. 도착 frame을 pose confidence와 최소 overlap 조건으로 먼저 거른다.
  2. 아직 안 쓴 frame에는 novelty 기반의 제한된 probe 기회를 준다.
  3. probe 후에는 실제 learning progress를 EMA로 추정한다.
  4. 새 frame의 첫 기회와 기존 cluster의 replay를 동일한 U(v,t) queue에서 경쟁시킨다.
  5. 최대 utility가 현재 shadow price μ(t)보다 작으면 GPU를 tracking에 양보하거나 polish를 쉰다.
아직 결정하지 않은 설계

m̂를 reference loss 감소로 측정할지, 인접 view cluster loss 감소로 측정할지, 또는 저해상도 virtual Adam step으로 예측할지는 실측 비용과 상관 분석 후 결정한다. 현재 문서는 특정 구현을 채택하지 않는다.

과적합 방지 Scene-specific fps와 final-eval feedback을 피한다

  • 최종 정책에 fps 상수를 넣지 않는다. 카메라가 정지하면 적게, 빠르게 움직이면 많이 admission되는 내용 기반 규칙을 사용한다.
  • Final fixed-eval은 scheduler에 사용하지 않는다. 별도의 causal reference buffer 또는 rotating anchor를 사용하고 최종 평가는 완전히 분리한다.
  • Frame보다 view cluster를 배분 단위로 검토한다. 30 fps 인접 frame이 같은 정보로 30표를 얻는 것을 막는다.
  • 동일 rule을 여러 장면·속도·budget에 재튜닝 없이 적용한다. threshold를 장면별 PSNR로 맞추지 않고, normalization된 novelty와 ms당 learning progress를 사용한다.
  • 실험은 MSE-vs-GPU-ms로 비교한다. Gaussian 수와 view 수에 따라 step 비용이 달라지는 문제를 제거한다.

한 문장 모델

working hypothesis

고정 fps로 dense frame을 모두 쓰는 것이 최종 목표가 아니다. Budget 안에서 비중복 관측에는 첫 학습 기회를 주고, 이미 선택된 view cluster에는 실측 한계 이득이 유지되는 동안만 replay를 배정하며, 모든 활성 action의 기대 품질 이득/GPU-ms가 비슷해지는 지점에서 멈춘다.

관련 근거와 연결

  • CONVERGE — Coverage Optimization for Camera View Selection: Fisher gain을 directional coverage로 근사하는 Problem A의 핵심 연결.
  • GRAD-MATCH, GLISTER: training/validation gradient를 근사하는 subset 및 update 선택.
  • TracIn: 한 training update가 reference/test loss에 미치는 1차 영향의 gradient-dot-product 근사.
  • RHO-LOSS: hard/noisy sample과 실제로 learnable하고 worth-learning인 sample을 구분하는 online batch selection 관점.
  • Neural Field Soft Mining: high-error 영역의 importance sampling을 통한 neural-field 수렴 가속 사례.
  • SA-ResGS (preprint): 강한 view dissimilarity가 multi-view overlap을 약화할 수 있다는 최근 관찰.
