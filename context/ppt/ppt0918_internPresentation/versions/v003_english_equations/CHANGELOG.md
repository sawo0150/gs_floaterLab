# 발표자료 변경 이력

| 버전 | 변경 | 보존 범위 |
|---|---|---|
| v001_initial | 최초 10장. 송채현을 발표자로 잘못 강조했던 역사적 버전 | 기존 PPT/PDF만. 정확한 당시 소스는 남아 있지 않음 |
| v002_korean_cover | 박상원, 김동휘, 송채현을 같은 크기로 표기 | PPT/PDF, 소스, 입력, 렌더링 |
| v003_english_equations | 영문 이름 나열; 3.1 비례식; 3.2 정규화 분산·엔트로피 목적함수와 softmax; 버전 보존 도입 | PPT/PDF, 소스, 입력, 수식, 렌더링, SHA-256 manifest |

각 versions/ 하위 폴더는 발행 이후 수정하지 않는다. 변경 시 새 버전을 만든다.
latest/는 마지막으로 발행한 버전을 가리킨다. 루트의 PPT/PDF는 작업본이다.
Carve 슬라이드 및 나머지 내용은 v003에서 수정하지 않았다.
