# 3.2 Entropy-Regularized Count Balancing (ERCB) — 무엇을 쓸 것인가 (v02, 2026-09-06)

> 한 줄 claim: **선택 횟수 불균형을 entropy 정규화 문제로 두면 해가 유일하게 정해진다.**
> 5문단, 수식 2개, 90줄 = 0.82 p.
>
> ★ P1 은 **"정확한 대상"이 아니라 "이상적 스케줄이 원하는 두 가지"**로 연다.
> 그래야 목적함수의 **두 항이 각각 (a)(b) 에 대응**하는 것이 보인다 —
> entropy 가 수학적 편의가 아니라 **요구사항 하나**임이 드러난다.

## ⚠ 대리(proxy)와 목표를 구분한다

목표는 **(b) 전후반 수렴 편차를 줄이는 것**이고, 우리가 최적화하는 것은 **선택 횟수**다.
exp72 는 이 둘이 갈라질 수 있음을 보였다:

| Scene | scheduler | PSNR | middle/first |
|---|---|---:|---:|
| aria1253 | K=128, β=0.02 | −0.084 | **0.971** |
| aria1253rot | baseline | — | 0.758 |
| aria1253rot | K=128, β=0.02 | **+0.362** | **0.520** |

**품질은 좋아졌는데 균등화 지표는 나빠진 장면이 있다.** exp72 카드는
*"이 family 가 일반적으로 lifetime-count equality 를 개선한다는 주장은 기각한다"* 고 명시한다.
→ P1 에서 목표를 (b) 로 세우되 **count 는 대리임을 밝히고**, P5 에서 갈라진 지점을 보고한다.
숨기는 것보다 이쪽이 강하다.

## 유도의 뼈대 — 이상적 요구에서 세 번 완화한다

chen2026cover §4 의 "정확 → 완화 → 실용"을 한 소절로 압축한 형태.

```
정확     전체 run 의 최종 count 분산을 최소화하는 선택 시퀀스
         ← 도착 과정이 아직 안 알려진 조합 최적화. 온라인에서 못 푼다
  ↓ 완화 1 (P2)
         한 step greedy: potential Φ 의 즉각 증가량만 최소화
         → 결정론적 "가장 적게 뽑힌 것" 규칙. 무작위성이 사라진다
  ↓ 완화 2 (P3)
         결정론적 argmin 대신 entropy 정규화된 기댓값 최소화
         → Gibbs 해. 유일하다
  ↓ 완화 3 (P4)
         매 선택마다 p 를 다시 계산하지 않고 block 시작 시점 count 를 고정
         → Plackett–Luce 비복원 추출
```

★ 완화 단계를 명시하면 **P4 의 "1차 근사"가 비로소 말이 된다.** v01 은 근사라고만 하고
*무엇의* 근사인지가 없었다.

## 문단 계약

| # | 하는 이야기 | 줄 | 수식 |
|---|---|---:|---|
| **P1** | **이상적인 스케줄이란 무엇인가.** 집합은 무한정 자라는데(§3.1) 단위시간당 update 는 늘지 않으므로 **view 당 노출이 줄고 순서의 중요성이 커진다.** 이상적 스케줄이 원하는 것 둘:<br>**(a) 섞임** — 연속한 update 가 상관 없는 gradient 를 봐야 한다. 궤적 순서대로 넣으면 연속 step 이 거의 같은 장면을 보아 국소만 쫓고 전역 진행이 정체된다. **셔플링이 존재하는 이유**<br>**(b) 전후반 편차 제한** — 자라는 집합에서 균등 추출하면 초반 view 가 훨씬 많이 노출되어 **시작은 선명하고 끝은 흐린 지도**가 된다. 완전 균등까지는 아니고 편차를 눌러야 한다<br>**이 둘은 서로 당긴다** — 최대 섞임 = 균등 = 최대 편차 / 완전 균등화 = 결정론 = 섞임 0. 그래서 **두 휴리스틱의 배합이 아니라 원리적 손잡이**가 필요하다 | 16 | |
| **P2** | **(b) 를 potential 로 형식화.** `Φ` 정의 (4). `Δ_iΦ = n_i − n̄ + ½(1−1/N)` — **inline.** 마지막 항이 `i` 에 무관 → greedy 는 **가장 적게 뽑힌 것 고르기**로 환원. **결정론적이므로 P1 이 경고한 (a) 를 그대로 잃는다** | 10 | (4) |
| **P3** | **DERIVING (완화 2) + 등식 감사.** ★ **(a) 를 패치가 아니라 항으로 되살린다** — 첫 항이 (b), 둘째 항이 (a), `τ` 가 P1 이 요구한 손잡이다. argmin 대신 `min_p Σ p_i Δ_iΦ − τH(p)`. `τ→0` 결정론, `τ→∞` 균등. 정상조건 → `p_i ∝ exp(−Δ_iΦ/τ)`, 공통항이 정규화에서 소거 → (5), `β=1/τ`. **"유일하다"와 그 근거**(p 에 대해 선형 + τ×음엔트로피 = 강볼록, 콤팩트 볼록집합 위) . 이어서 **등식 감사**: `β=0` 은 `K ≥ N_t` 일 때만 random reshuffling 과 일치, `K<N_t` 면 block 은 순열이 아니라 부분집합. 그리고 **그때도 수렴 보장은 안 가져온다** (집합이 자라고 비볼록) | 22 | (5) |
| **P4** | **EXTENSION (완화 3) + 가정 원장.** **첫 문장에서 이름을 밝힌다** — 가중치 `exp(−βn_i)` 로 K개를 순차 비복원 추출하는 것은 **Plackett–Luce** 추출(= Gumbel-Top-k). (5)를 정확히 적용하려면 매 선택마다 `p` 재계산이 필요하나, block 시작 count `n_i^(b)` 를 고정해 K개를 뽑는다. **가정 원장**: block 안에서 count 는 최대 1 증가하므로 고정 가중치는 정확한 순차 가중치와 선택 1회당 최대 `e^β` 배 차이 → 작은 `β` 에서 1차 효과. **"근사"라고만 하고 넘어가지 말고 조건을 쓴다.** 남은 무작위성은 `ρ_H` 로 계측(정의는 §4) | 22 | |
| **P5** | **대리와 목표가 갈라지는 지점.** count 는 (b) 의 **대리**이고 둘은 어긋날 수 있다. 한 궤적에서 middle/first 가 **0.758 → 0.520 으로 나빠졌는데 held-out PSNR 은 +0.362 dB 좋아졌다.** 다른 궤적에선 0.971 로 균등했다. **따라서 이 family 가 lifetime-count equality 를 일반적으로 개선한다고 주장하지 않는다** — exp72 가 그 주장을 명시적으로 기각했고, 더 큰 `β` 는 0.605 까지만 회복하며 entropy 를 0.9825 로 떨어뜨렸다 | 14 | |

## 등식 감사를 P3 에 두는 이유

chen2026cover §4.1 은 등식이 깨지는 **바로 그 지점**에서 감사한다:

> *"However, note that with additional constraints, Eq. (7) is **no longer equality**.
> Rather, we have the tight bound by Cauchy--Schwarz ... **Regardless**, minimizing Eq. (8)
> subject to additional constraints still applies upward pressure to the FIG."*

별도 문단으로 빼지 않는다. 뒤로 미루면 **사과처럼** 읽히고, 제자리에 있으면 **유도의 일부**로 읽힌다.
