
\section{Method}
\label{sec:method}

Our goal is to improve the rendering and geometric quality of the Gaussian map under the limited mapping updates available in online 3DGS SLAM. Instead of letting keyframe selection fix both the set of training views
and which of them each mapping iteration sees, we decouple the two and drive each from optimization progress already observed---the number of completed mapping updates and how many times each view has been selected. We first add the frames between keyframes to the training views and let the number of completed mapping updates, rather than the keyframe rule, determine how fast that set grows (\S\ref{ssec:growth}). We then sample views from a distribution that favors under-selected views while retaining stochasticity, and use sampling without replacement to reduce repetitive view selections across consecutive mapping updates (\S\ref{ssec:ercb}). Finally, we constrain free-space violations that photometric supervision does not directly constrain, using only observations that have already arrived, so that geometry converges sooner (\S\ref{ssec:carve} -  Detailed sentences need to be modified).

\subsection{Optimization-Guided View Growth}
\label{ssec:growth}

Offline 3DGS optimizes a fixed set of views, whereas GS-SLAM must update the map as new observations arrive while sharing computation with tracking. Mapping can therefore perform only a limited amount of optimization during an online run. Several real-time GS-SLAM systems optimize the map using a bounded set of keyframes~[15,16,17]. However, keyframe selection is not designed solely to provide dense photometric supervision for map optimization~[cite]. Our results in Table~X show that including frames between keyframes improves map quality under the same number of mapping updates. At the same time, removing earlier views can reduce supervision for regions that are weakly covered by the remaining set and makes it harder to distribute optimization across the full trajectory. We therefore retain previously added training views and allow the training set to grow as new observations become available.

Growing the training set introduces a competing effect. Adding views provides more supervision, but the same mapping updates must then be distributed over a larger set, reducing how often each view can be revisited. The appropriate rate at which views should be added therefore depends on how much optimization can actually be performed. In an online setting, this amount cannot be determined exactly in advance: when a new frame arrives, both the remaining length of the sequence and the number of mapping updates that will eventually be completed are unknown. The decision to include that frame must nevertheless be made online. We therefore make the growth of the training set follow the optimization work that has actually been completed, rather than a schedule fixed before the run.

Let $S(t)$ denote the number of mapping updates completed by time $t$, counting an update only after it has finished. Let $\mathcal{A}_t$ be the training-view set at time $t$, and let $N_0=|\mathcal{A}_0|$ be the number of initial views. We use a single parameter, $\kappa$, to specify the number of completed mapping updates required for each additional view. The number of views added by time $t$ is then constrained by
\begin{equation}
    \kappa\left(|\mathcal{A}_t|-N_0\right)
    \leq S(t).
    \label{eq:view_growth_constraint}
\end{equation}
Solving Eq.~\eqref{eq:view_growth_constraint} for the training-set size gives
\begin{equation}
    N_{\max}(t)
    =
    \min\left(
        M(t),
        N_0+\left\lfloor\frac{S(t)}{\kappa}\right\rfloor
    \right),
    \label{eq:view_growth_bound}
\end{equation}
where $M(t)$ is the number of views available by time $t$. The minimum prevents the training set from exceeding the views that have already arrived, and the floor accounts for views being added one at a time. When additional views are available, one view can therefore be added for every $\kappa$ completed mapping updates. Measured in completed mapping updates, this growth rate is determined only by $\kappa$: it does not decrease as the training set becomes larger and does not depend on how views already in the set are selected for optimization. This separates the decision of when to add new views from the decision of which existing views to optimize; Section~3.2 addresses the latter.

\subsection{Entropy-Regularized View Sampling}
\label{ssec:ercb}

The training-view set grows over time as new observations become available and mapping optimization proceeds. A simple strategy is to sample uniformly from the views currently in the set. Although this gives every available view the same probability at a given time, it does not account for when each view entered the training set. Views added early remain eligible for selection for longer and can therefore receive substantially more mapping updates, whereas views added later have fewer opportunities to be selected. If this difference accumulates, optimization can become unevenly distributed along the trajectory, leaving less frequently optimized regions with lower reconstruction quality. We therefore want to give more opportunities to views that have received fewer updates. A purely deterministic least-count rule, however, removes the randomization commonly used in stochastic optimization to reduce systematic ordering effects~[cite]. This is particularly relevant for SLAM, where nearby camera frames often contain highly similar observations. Our goal is therefore to favor under-selected views while retaining randomness in the selection process.

Let \(s\) index mapping-view selections, and let \(N_s\) be the number of views available for training at selection step \(s\). Let \(n_i\) denote the number of times view \(i\) has been selected for a mapping update. We denote the mean selection count by

$$
\bar n = \frac{1}{N_s}\sum_i n_i.
$$

Because the scale of the raw count variance changes as selections accumulate, we measure the dispersion relative to the current mean count:
\begin{equation}
\Phi(\mathbf n)
=
\frac{1}{2N_s\bar n}
\sum_{i=1}^{N_s}
(n_i-\bar n)^2.
\label{eq:count_dispersion}
\end{equation}
A smaller \(\Phi\) indicates that the accumulated selection counts are more evenly distributed across the current training views. Let \(T=\sum_i n_i=N_s\bar n\) be the total number of selections made so far. For a single selection step, with the training set held fixed, selecting view \(i\) once more changes the dispersion by
\begin{equation}
\Delta_i\Phi
=
\Phi(\mathbf n+\mathbf e_i)-\Phi(\mathbf n)
=
\frac{n_i}{T+1}+C_s,
\label{eq:count_dispersion_increment}
\end{equation}
where \(C_s\) is independent of the selected view. Thus, views with smaller selection counts produce a smaller increase in \(\Phi\). Greedily minimizing this change would recover a deterministic least-count rule. Instead, we use \(\Delta_i\Phi\) to define a probability distribution over the available views.

Let \(p_i\) denote the probability of selecting view \(i\) for the next mapping update. We seek a distribution that favors views with smaller \(\Delta_i\Phi\) without concentrating all probability on a single view. We express these two objectives jointly as
\begin{equation}
\min_{\mathbf p\in\Delta}
\sum_i p_i \Delta_i\Phi
-
\tau H(\mathbf p),
\label{eq:entropy_sampling_objective}
\end{equation}
where \(H(\mathbf p)=-\sum_i p_i\log p_i\), \(\Delta\) denotes the probability simplex, and \(\tau>0\) controls the strength of the entropy term. The first term favors views that have been selected less often, while the second discourages the distribution from becoming overly concentrated. Solving Eq.~\eqref{eq:entropy_sampling_objective} under the constraint \(\sum_i p_i=1\) gives
\begin{equation}
p_s(i)
=
\frac{
\exp!\left(-\Delta_i\Phi/\tau\right)
}{
\sum_j \exp!\left(-\Delta_j\Phi/\tau\right)
}.
\label{eq:entropy_sampling_general}
\end{equation}
Substituting Eq.~\eqref{eq:count_dispersion_increment} removes the term shared by all views and yields
\begin{equation}
p_s(i)
=
\frac{
\exp(-\beta_s n_i)
}{
\sum_j \exp(-\beta_s n_j)
},
\qquad
\beta_s
=
\frac{1}{\tau(T+1)}.
\label{eq:entropy_view_sampling}
\end{equation}
Views with fewer previous selections therefore receive higher probability, while every available view retains a nonzero probability of being selected. For a fixed \(\tau\), \(\beta_s\) decreases as the total number of selections grows, so the influence of a fixed count difference is gradually reduced relative to the accumulated selection history.

Equation~\eqref{eq:entropy_view_sampling} defines the distribution for a single view selection. If each mapping update samples independently with replacement, however, a small number of high-probability views can be selected repeatedly over a short interval while other views receive no update. To reduce such short-term repetition, we select \(K\) distinct views without replacement for the next \(K\) mapping updates. At the beginning of each group, we compute the sampling probabilities from the current selection counts and use them to select \(K\) distinct views. Each selected view is then used once, and the updated counts are used to compute the distribution for the next group. This preserves the preference for under-selected views while ensuring that the same view is not repeatedly selected within the group. The parameter \(K\) therefore determines the interval over which repeated selections are prevented: \(K=1\) reduces to single-view sampling, whereas larger \(K\) increases the variety of views used over consecutive mapping updates. We evaluate the effect of \(K\) in Sec.~\ref{sec:exp}.

\subsection{Causal Ray-Space Geometry Supervision}
\label{ssec:carve}

Photometric supervision constrains the composited color but does not uniquely
determine where opacity lies along a ray: a premature Gaussian can reproduce
the observed color while occupying known free space. A conventional rendered
depth loss is also insufficient because it first compresses all contributors
to one mean depth, allowing separated front and back modes to cancel. We
therefore supervise the first-termination process induced by Gaussian
compositing using only depth observations available at the current time. This
gives two complementary constraints: \emph{Carve} suppresses termination before
the observed surface, while \emph{Hit} places termination mass at that surface.

\paragraph{Ray termination.}
For a depth-ordered set of Gaussian contributors to ray $r$, let
$\alpha_i^0$ be the base opacity, $G_{ri}^{\mathrm{2D}}$ the projected
Gaussian value at the pixel, and $z_{ri}$ its camera-space depth. The effective
alpha, incoming transmittance, and termination weight are
\begin{equation}\label{eq:ray_termination}
  a_{ri}=\alpha_i^0G_{ri}^{\mathrm{2D}},\qquad
  T_{ri}=\prod_{j<i}(1-a_{rj}),\qquad
  w_{ri}=T_{ri}a_{ri}.
\end{equation}
The remaining no-hit mass is
$T_{\mathrm{end},r}=\prod_i(1-a_{ri})$, and
$\sum_iw_{ri}+T_{\mathrm{end},r}=1$. We equivalently introduce a categorical
first-termination index $I_r$ with
$p(I_r=i\mid\Theta)=w_{ri}$ and
$p(I_r=\varnothing\mid\Theta)=T_{\mathrm{end},r}$. This is an interpretation
of deterministic alpha-compositing mass, not a stochastic renderer.

For each multi-view-verified keyframe ray, VIGS provides a BA-refined depth
$D_r$. Its latent first-surface depth $Z_r^\star$ is represented by an
external posterior
\begin{equation}\label{eq:surface_posterior}
  \begin{aligned}
  q_r(z)&=p(Z_r^\star=z\mid\mathcal O_r)
  =\mathcal N(z;D_r,\tau_r^2),\\
  F_r(b)&=\Phi\!\left(\frac{b-D_r}{\tau_r}\right).
  \end{aligned}
\end{equation}
where $\mathcal O_r$ denotes the front-end observations. We stop gradients
through $D_r$ and $\tau_r$, keeping this evidence independent of the Gaussian
map parameters $\Theta$.

\paragraph{Free-space likelihood (Carve).}
Given a surface at $z$ and a safety margin $m_r$, the target event is
\begin{equation}\label{eq:carve_event}
  \mathcal E_r^{\mathrm F}(z)
  =\{\text{no model termination before }z-m_r\}.
\end{equation}
Its conditional likelihood is exactly the transmittance
$p(\mathcal E_r^{\mathrm F}(z)\mid Z_r^\star=z,\Theta)
=T_\Theta(r,z-m_r)$. Taking the posterior expectation of its conditional NLL
gives
\begin{align}
  \mathcal L_{\mathrm{C\text{-}ENLL}}
  &=\frac{1}{|\mathcal R_D|}\sum_{r\in\mathcal R_D}\sum_i
    \gamma_{ri}\big[-\log(1-a_{ri})\big], \label{eq:carve_enll}\\
  \gamma_{ri}
  &=p(Z_r^\star>z_{ri}+m_r\mid\mathcal O_r)
    =1-F_r(z_{ri}+m_r), \nonumber
\end{align}
where $\mathcal R_D$ is the set of verified depth rays. Thus, a Gaussian is
penalized in proportion to the posterior probability that it lies in observed
free space. With geometry detached, minimizing Eq.~(\ref{eq:carve_enll})
monotonically decreases only its opacity.

Alternatively, marginalizing the compatibility event before taking the NLL
gives
\begin{align}
  P_{\mathrm{C\text{-}MARG},r}
  &=\int q_r(z)T_\Theta(r,z-m_r)\,\mathrm dz \nonumber\\
  &=T_{\mathrm{end},r}+\sum_iw_{ri}F_r(z_{ri}+m_r), \label{eq:carve_marg}\\
  \mathcal L_{\mathrm{C\text{-}MARG}}
  &=-\frac{1}{|\mathcal R_D|}\sum_{r\in\mathcal R_D}
  \log(P_{\mathrm{C\text{-}MARG},r}+\epsilon). \nonumber
\end{align}
Equation~(\ref{eq:carve_marg}) is the exact NLL of the stated compatibility
event under an external $q_r$, whereas Eq.~(\ref{eq:carve_enll}) is its
posterior-expected conditional NLL. Jensen's inequality gives
$\mathcal L_{\mathrm{C\text{-}MARG}}
\leq\mathcal L_{\mathrm{C\text{-}ENLL}}$, so the latter is more conservative.
Both objectives permit a no-hit solution and therefore remove free-space
violations without, by themselves, creating surface coverage.

\paragraph{First-hit likelihood (Hit).}
Carve specifies where termination should not occur; Hit additionally explains
the measured surface. Conditioned on termination at Gaussian $i$, we use the
forward observation model
\begin{equation}\label{eq:hit_observation}
  k_{ri}=p(D_r\mid I_r=i,\Theta)
  =\mathcal N(D_r;z_{ri},\sigma_r^2),
\end{equation}
where $\sigma_r$ is calibrated measurement noise, not Gaussian thickness.
Marginalizing the latent termination index yields
\begin{align}
  p(D_r,I_r\neq\varnothing\mid\Theta)
  &=\sum_i p(D_r\mid I_r=i,\Theta)p(I_r=i\mid\Theta) \nonumber\\
  &=\sum_iw_{ri}k_{ri}, \label{eq:hit_likelihood}\\
  \mathcal L_{\mathrm{HIT}}
  &=-\frac{1}{|\mathcal R_D|}\sum_{r\in\mathcal R_D}
  \log\!\left(\sum_iw_{ri}k_{ri}+\epsilon\right). \nonumber
\end{align}
Writing $A_r=\sum_iw_{ri}$ decomposes each ray loss into
$-\log A_r-\log\sum_i(w_{ri}/A_r)k_{ri}$: the first term demands a finite hit,
and the second aligns the complete termination distribution with $D_r$.
Consequently, near-surface components gain termination mass, premature
occluders lose opacity when they block a better downstream explanation, and
components with nonzero mixture responsibility receive position gradients
toward $D_r$. Unlike Carve, the canonical Hit objective therefore optimizes
opacity, position, and projected shape.

\paragraph{Non-overlapping Carve--Hit objective.}
Adding global Carve and Hit losses independently can count the same front
transmittance twice because every $w_{ri}$ already contains $T_{ri}$. For an
exact factorization, define a free-space boundary $B_r=D_r-m_r$, an upper
surface boundary $U_r$, and
\begin{equation}\label{eq:carve_hit_partition}
  \mathcal F_r=\{i:z_{ri}<B_r\},\qquad
  \mathcal S_r=\{i:B_r\leq z_{ri}\leq U_r\}.
\end{equation}
Let
$T_r^{\mathrm F}=\prod_{i\in\mathcal F_r}(1-a_{ri})$ and reset
transmittance inside the surface set,
\begin{equation}\label{eq:local_hit_weight}
  \widetilde w_{ri}^{\mathrm S}
  =a_{ri}\!\!\prod_{\substack{j\in\mathcal S_r\\z_{rj}<z_{ri}}}
  (1-a_{rj}).
\end{equation}
Since $w_{ri}=T_r^{\mathrm F}\widetilde w_{ri}^{\mathrm S}$ for
$i\in\mathcal S_r$, the restricted first-hit NLL factorizes as
\begin{equation}\label{eq:carve_hit}
  \mathcal L_{\mathrm{C+H}}(r)
  =-\log T_r^{\mathrm F}
  -\log\!\left(
  \sum_{i\in\mathcal S_r}\widetilde w_{ri}^{\mathrm S}k_{ri}
  +\epsilon\right).
\end{equation}
The first term suppresses opacity only in front of the surface boundary; the
second creates and aligns termination mass only in the local surface region.
Resetting transmittance at $B_r$ prevents double penalization. Replacing the
hard first term with Eq.~(\ref{eq:carve_enll}) gives an uncertainty-aware
composite objective, but no longer the exact factorization in
Eq.~(\ref{eq:carve_hit}).

\paragraph{Online integration.}
We evaluate these objectives only on spatially balanced, multi-view-verified
depth rays. The existing rasterizer already computes
$(z_{ri},G_{ri}^{\mathrm{2D}},a_{ri},T_{ri},w_{ri})$ in its front-to-back
contributor loop; we accumulate the required likelihood in the same pass and
combine it with the mapping loss before a single backward pass. The additional
work is therefore linear in the number of selected ray--Gaussian pairs and
does not require a second full-frame render. Carve stops gradients through
depth, ordering, and footprint and updates opacity only, avoiding unreliable
position updates across sorting discontinuities. Hit retains full gradients
for surface contributors. The factorized objective applies these routes
separately to $\mathcal F_r$ and $\mathcal S_r$.
