# 공통 평가 프로토콜 v01 (2026-09-05)

> **모든 run의 `manifest.json` 은 이 문서의 버전을 기록한다.**
> 프로토콜이 바뀌면 이전 run의 숫자는 그대로 비교할 수 없다. 그래서 이 문서는 버전 폴더다.

## strict streaming 계약

한 run이 "strict"로 인정되려면 아래를 **동시에** 만족해야 한다.

| # | 조건 |
|---|---|
| S1 | 입력은 timestamp 순 RGB photo + IMU만. MPS 후처리 trajectory/depth/point cloud **0개** |
| S2 | 고정 calibration은 허용. 학습에 쓰는 pose/depth는 해당 시점까지 **online 추정한 값만** |
| S3 | fixed 1.5× live budget (aria1253 기준 97.65초 이내) |
| S4 | 마지막 센서 frame 뒤 optimizer update **0회** (zero-tail) |
| S5 | held-out evaluator frame은 Gaussian mapping supervision에서 **완전히 제외** |
| S6 | 인과 순서 유지 — 어떤 청크/프레임도 미래 keyframe 정보를 쓰지 않음 |

## 평가 지표

| 범주 | 지표 | 비고 |
|---|---|---|
| Appearance | **held-out** PSNR / SSIM / LPIPS, late temporal bins | ⚠ train/KF PSNR 단독 판정 **금지** (프로젝트 확립 원칙) |
| Geometry | region GT (`floater_metric_region.py`) ROC-AUC / AP / precision@visual budget / recall | ray-density와 상호보완 |
| Scheduler | ρ_H (normalized conditional entropy), lifetime count middle/first, 최종 pool 크기 | |
| System | p50/p95 latency, sensor/state/topology drop, replay step/s, score-age p95, zero-tail 확인 | |

### ⚠ held-out 하네스 함정

3dgs-custom `render.py --eval` 은 `--eval` 시 **llffhold-8**(전체 프레임 8번째)을 쓰고
`test.txt` 를 무시한다 (exp48에서 발견). 특정 구간 분석 시 프레임 매핑은 반드시
llffhold-8 기준으로 한다.

## 반복과 통계

- 최종 표에 들어가는 숫자는 **3회 반복의 mean ± std**.
- 단일 run 최고치를 대표값으로 쓰지 않는다.
  (exp57: 단일 최고 27.0039 vs 평균 26.8419 — 3회 중 1회만 27 돌파)
- run-to-run 노이즈는 ORB 트랙 실측 ±0.33dB. 이보다 작은 차이는 유의하다고 쓰지 않는다.

## acceptance gate (사전 등록)

`context/research/2026-09-01_carve_kf_viewset_mission.html` §7.6 의 제안값을 출발점으로 한다.
**숫자는 label prevalence와 기존 exp40 ROC/region 결과를 본 뒤 확정하고, 그 뒤에는 고정한다.**

| Claim | Gate | 실패 시 해석 |
|---|---|---|
| Rate-invariant | 동일 trace pace sweep에서 PSNR range ≤ 0.30 dB, topology drop 0 | scheduler/queue 문제 |
| Detector | 두 direct-label scene에서 AUC ≥ 0.95, AP가 prevalence 대비 명확히 우세 | evidence/score 문제 |
| Availability | visible floater fresh-before-action recall ≥ 90%, score-age p95 제한 | refresh 문제 |
| Action | ≤0.75% visual budget에서 floater recall ≥ 50%, significant surface precision ≥ 95% | action/certificate 문제 |
| Joint quality | strict held-out ΔPSNR ≥ −0.2 dB, region geometry 일관 개선 | geometry–appearance coupling 문제 |
