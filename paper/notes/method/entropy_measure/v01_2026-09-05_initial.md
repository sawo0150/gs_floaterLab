# 유도 노트 — Normalized Conditional Entropy ρ_H (v01, 2026-09-05)

원 출처: `context/research/vigs_slam_method_discussion_bullets.md` §5 "Entropy 측정"

## 정의

각 draw의 uniform maximum은 `log |W_b^(k)|` 이다. run-level 정규화:

```
ρ_H = Σ_{b,k} H(p_{b,k})  /  Σ_{b,k} log |W_b^(k)|
```

`ρ_H = 1` 이면 **같은 remaining support에서** uniform draw와 동일한 entropy.

## 왜 이 정규화인가

remaining set 크기가 draw마다 줄어들기 때문에(`|W|` 가 K→1), 절대 entropy를 그대로
보고하면 block 길이에 따라 값이 달라진다. 분모를 같은 support의 uniform maximum으로
두면 **"얼마나 uniform에 가까운가"만** 남는다.

## 보고 시 반드시 함께 쓸 것

- "같은 remaining support 대비" 정규화값이라는 점.
  이걸 빼면 리뷰어가 "entropy 0.998이면 거의 uniform인데 그럼 β가 무슨 소용?"이라고 읽는다.
- 실제로 그 질문의 답은 **C5**: 높은 one-step entropy만으로는 부족하고
  **긴 without-replacement coverage(K)** 가 품질을 만든다.
  exp72에서 `K=1, β=0` 이 −2.863dB인 것이 직접 증거.

## 열린 질문

- ρ_H 만으로는 "coverage가 길었는가"를 못 본다. **block 길이 분포**나
  `max_i n_i − min_i n_i` 같은 보조 통계를 함께 보고해야 하지 않나?
- 모든 log는 natural logarithm 사용 — 본문에 명시할 것.
