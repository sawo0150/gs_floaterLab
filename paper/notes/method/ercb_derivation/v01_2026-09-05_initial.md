## 1. Count imbalance potential

```
Φ(n) = ½ Σ_{i=1}^{N} (n_i − n̄)²,     n̄ = N⁻¹ Σ_i n_i
```

view i를 한 번 더 학습했을 때의 **정확한** 증가량:

```
Δ_i Φ = Φ(n + e_i) − Φ(n) = n_i − n̄ + ½(1 − 1/N)
```

마지막 항은 **모든 i에 공통**이다. 따라서 argmin/softmax에서 소거되고,
"count가 작은 view를 고를수록 다음-step imbalance 증가가 작다"가 정확히 성립한다.

## 2. Entropy-regularized 선택 문제

simplex `Δ_N` 위에서

```
p_t = argmin_{p ∈ Δ_N} [ Σ_i p_i (n_i − n̄) − τ H(p) ],    H(p) = −Σ_i p_i log p_i
```

τ > 0 은 entropy temperature, `β = 1/τ`.

## 3. Lagrangian

`−τH(p) = τ Σ_i p_i log p_i` 이므로

```
L(p, λ) = Σ_i p_i (n_i − n̄) + τ Σ_i p_i log p_i + λ( Σ_i p_i − 1 )
```

stationary condition:

```
∂L/∂p_i = (n_i − n̄) + τ(log p_i + 1) + λ = 0
⇒ p_i = exp[ −(n_i − n̄)/τ ] · exp[ −1 − λ/τ ]
```

두 번째 지수항은 모든 view 공통 정규화 상수. `Σ_i p_i = 1` 을 적용하면

```
p_t(i) = exp[−β(n_i − n̄)] / Σ_j exp[−β(n_j − n̄)]
       = exp(−β n_i) / Σ_j exp(−β n_j)          ← n̄ 소거
```

τ > 0 이면 entropy 항이 strictly convex이므로 이 stationary point는
simplex **내부의 유일한** minimizer다.

**구현상 이점:** `n̄` 이 소거되므로 평균을 추적할 필요가 없고 수치적으로도 안정적이다.

## 4. K-view statistical block

one-step categorical sampling은 같은 view를 연속 선택해 full-pool coverage가 쉽게 깨진다.
block 시작 시 count를 `n_i^(b)` 로 **snapshot 고정**하고 비복원 추출:

```
W_b^(0) = A_{t_b}
p_{b,k}(i) = exp(−β n_i^(b)) / Σ_{j ∈ W_b^(k)} exp(−β n_j^(b)),   i ∈ W_b^(k)
I_{b,k} ~ p_{b,k},   W_b^(k+1) = W_b^(k) \ {I_{b,k}}
```

K개를 뽑거나 remaining이 비면 block을 닫고, 다음 block은 그 시점의 pool로 재생성.
block 중간 도착 view는 **다음 block부터** 참여.

## 5. 두 극단 — 정확한 문장

| | 결과 |
|---|---|
| `β = 0` | 현재 block의 모든 ordered K-subset에 균등. **`K ≥ N_t` 일 때에만** 전체 pool의 `N_t!` permutation에 정확히 균등 |
| `β → ∞` | randomized least-count에 접근 |
| 유한 `β > 0` | soft preference + 모든 remaining view에 non-zero support |

⚠ `K ≥ N_t` 조건을 빼먹으면 "full-pool random reshuffling이다"가 **틀린 문장**이 된다.
